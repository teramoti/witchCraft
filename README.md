# 花染めの錬金ラボ - React/Phaser Project

GameJam用の元PJ版です。

## ゲーム本体
- `src/scenes/Start.js`

## 画像素材
- `assets/Image/gamejam_variants/flowers/`
- `assets/Image/gamejam_variants/potions/`
- `assets/Image/gamejam_variants/effects/`

## 素材追加
`Start.js` の `MATERIAL_VARIANTS` に画像を追加してください。
同じ色カテゴリの画像を増やすだけなら、色合成ロジックの変更は不要です。

## GameJam方針
見た目の種類は増やしていますが、ゲームルールは増やしていません。
短時間で説明できる「花を混ぜてお題色を作る」をコアにしています。
