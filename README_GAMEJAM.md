# 花染めの錬金ラボ / Flower Dye Alchemy Lab

元PJ（React + Vite + Phaser 4）の構成を維持したGameJam用ベータです。

## 重要
- ゲームロジック本体: `src/scenes/Start.js`
- Phaser起動境界: `src/game/GameManager.ts`
- タイトル画面: `src/app/screens/StartScreen/StartScreen.tsx`
- リザルト画面: `src/app/screens/ResultScreen/ResultScreen.tsx`
- `index.html` はViteの通常エントリであり、ゲームロジックは書いていません。

## 現在のルール
- 赤花 + 青花 = 紫染料
- 青花 + 黄花 = 緑染料
- 赤花 + 黄花 = 橙染料
- 同じ色同士 / 枯れ花を混ぜる = 濁り / スコア・時間ペナルティ
- マウスドラッグで隣の花へ重ねる
- 現在のお題に加えて「次の2色」を表示し、先読みできる
- NEXT色を先に作ると1本だけ `PREP` 予約でき、現在のお題の納品直後に連続納品される
- お題を連続成功するとコンボ加点。コンボには5秒の継続時間がある
- 3連続成功ごとに +2秒 と「虹花」を盤面へ投入
- 虹花はどの花と混ぜても現在のお題を完成できるボーナス素材
- 成功でFEVERゲージが貯まり、100%で8秒間スコア1.5倍
- 盤面には花だけを残し、完成ポーションは右側の大釜で演出する
- 現在のお題を作れる隣接ペアが0になった場合だけ自動救済し、理不尽な詰みを防止
- 数秒操作が止まると、現在のお題を作れる2マスが薄く光るヒントを表示
- 1〜4P交代制
- 制限時間終了後、全プレイヤー終了でリザルトへ遷移

## 素材バリエーション
通常の色カテゴリは7種類です。加えてゲーム中だけ使う `rainbow`（虹花）と `withered`（枯れ花）があります。
見た目の画像だけ複数登録しているので、ルールを増やさず盤面を華やかにできます。

- 赤花: 3種類
- 青花: 3種類
- 黄花: 3種類
- 紫ポーション: 3種類
- 緑ポーション: 3種類
- 橙ポーション: 3種類
- 失敗ポーション: 3種類
- 成功/リザルト用エフェクト: 3種類

追加口は `src/scenes/Start.js` の `MATERIAL_VARIANTS` です。
画像をimportし、対象色の配列へ `{ key, src }` を追加するだけで利用できます。

## GameJam向け設計メモ
- ルールを増やしすぎず、既存の「色を混ぜる」体験に山場だけ追加しています。
- `MATERIAL_VARIANTS` は見た目専用、`MIX_TABLE` は色理論、FEVER/虹花はゲームテンポ専用です。
- 素材を増やす担当とロジックを触る担当が分かれても衝突しにくい構成です。
- 盤面に完成ポーションを残さないのは、二次色同士の追加ルールが必要になってGameJamの実装量が膨らむのを防ぐためです。


## v5で追加したゲーム性
- `PREP`: 次のお題を先に合成して予約瓶へ保存。現在注文のあとに即納品できます。
- `QUICK BONUS`: お題が出てから早く完成させるほど最大+40点。
- `COMBO WINDOW`: コンボは5秒以内に次の正解を出すと継続します。
- `BOARD RESCUE`: 正解ペアが無い盤面だけ自動で1ペア生成します。
- `HINT`: 一定時間止まったプレイヤーには正解候補を薄く表示します。

この5つは新しい色ルールを増やさず、既存の「花を混ぜる」操作に判断とテンポを足すための処理です。
